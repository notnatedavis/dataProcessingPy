# dataProcessingPy

A Python toolkit for encrypting, shuffling, and reconstructing image, JSON, and video data.  
Designed for batch processing, the project turns media files into human‑readable (but obfuscated) text representations, applies spatial and character‑level permutations, and reverses the process.

## Introduction

`dataProcessingPy` is a collection of modular Python scripts that process files in bulk:

- **Images** ↔ encrypted `.txt` (RGB pixel data encoded as letters + digits)
- **JSON** ↔ character‑shuffled JSON (keys and string values obfuscated)
- **Video** ↔ encrypted frame‑by‑frame `.txt` files (using `ffmpeg`)

All operations support individual files or entire directories. The shuffling routines use a deterministic grid‑based spatial permutation and a fixed character substitution map, making the process reversible.

## Features

- **Image Encryption / Decryption**  
  - Single image (`indImgE.py`, `indImgD.py`) or entire folders (`foldImgE.py`, `foldImgD.py`)  
  - Automatically crops dimensions to multiples of `GRID_DIVISOR` for compatibility

- **Spatial & Character Shuffling (Images)**  
  - `foldImgShuf.py` – apply both spatial (grid slice rearrangement) and character shuffles  
  - `foldImgUnshuf.py` – reverse the process  
  - Works on `.txt` files generated by encryption

- **JSON Shuffling**  
  - `foldJsonShuf.py` – obfuscate JSON keys and string values using the same character map  
  - `foldJsonUnshuf.py` – restore original content

- **Video to Frames & Back**  
  - `videoToTxt.py` – extract video frames, crop to divisible dimensions, and save as encrypted `.txt` files (with `metadata.txt` and `index.txt`)  
  - `foldVidShuf.py` / `foldVidUnshuf.py` – apply spatial+character shuffle/unshuffle to all frames in a folder  
  - `txtToVideo.py` – reconstruct a `.mov` video from shuffled or unshuffled frame files using `ffmpeg`

- **Progress Bars** – `tqdm` integration for long operations (can be disabled with `--no-progress`)
- **Interactive Selection** – choose directories, folders, and files via numbered menus when arguments are omitted

## Usage

1. **Clone & enter**
   ```bash
   git clone https://github.com/notnatedavis/dataProcessingPy.git && cd dataProcessingPy
   ```

2. **Create virtual environment & activate**
    ```bash
    pyenv local 3.10.0
    python -m venv venv
    source venv/bin/activate # Linux / macOS
        # or
    venv\Scripts\activate    # Windows
    ```

3. **Install dependencies**
    ```bash
   pip install -r requirements.txt
   ```

4. **Run desired file**
    ```bash
    python x/x*
    ```

## Configuration

All global settings are defined in `common.py`, You can adjust :
- `VALID_DIRECTORIES` – list of base paths to quickly navigate
- `GRID_ROWS, GRID_COLS` – number of row/col slices for spatial shuffle (default 8×8)
- `SPATIAL_PERMUTATION` – a list of length `GRID_ROWS * GRID_COLS` defining how slices are rearranged
- `CHAR_SHUFFLE_MAP` – a 26‑letter substitution cipher for character‑level obfuscation
- `ROUNDING_MODE` – `'floor'`, `'ceil'`, or `'round'` for distributing leftover pixels when slicing
- `IGNORE` – set of folder names to skip when listing directories

`index.txt` (generated by `videoToTxt.py`) stores the permutation and character map used for a particular video, ensuring that shuffling and unshuffling are consistent even if `common.py` changes later.
